# Kritva SDK Review Checklist

- [ ] SDK boundary preserves upstream contract and runtime ownership.
- [ ] Exact upstream contract versions/commits are recorded.
- [ ] Public API, errors, timeout, cancellation and idempotency are explicit.
- [ ] ROS 2 and simulation remain optional.
- [ ] Dependencies and licenses are reviewed.
- [ ] Secrets and sensitive payloads are not logged.
- [ ] Unit, contract, integration and regression tests are correctly classified.
- [ ] Unimplemented gates remain NOT_IMPLEMENTED.
- [ ] CI evidence refers to exact commit.
- [ ] Simulation is not described as physical or safety validation.
- [ ] Task ID, milestone and acceptance criteria exist.
- [ ] PR and commit conventions are followed.
- [ ] Local status does not claim central acceptance.
