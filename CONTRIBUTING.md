# Contributing to Kritva SDK

Read `AGENTS.md`, `ARCHITECTURE.md`, `REQUIREMENTS.md` and `ACCEPTANCE_CRITERIA.md` first. Check the task and milestone in `planning/`. Confirm the upstream contract and version before implementing an adapter. Work on a branch and open a PR using the repository template. Add tests and documentation for behavior changes. Report exact commands, results, commit SHAs and CI run IDs.

Do not introduce public APIs, dependencies, transports or compatibility promises without review. Software and simulation tests do not establish physical safety. Contributions are subject to the repository license and applicable Kritva governance.
